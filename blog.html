Building a Task Manager with React Native

August 28, 2026

My ToDo App was my first real dive into React Native. I wanted to get comfortable with the core building blocks: components, screens, and navigation before jumping into anything more complex on mobile.

Tasks are managed with local component state, so add, complete, and delete actions all update the UI instantly without hitting any backend. I spent most of my time getting navigation between screens to feel smooth, and learning how React Native's layout system differs from plain CSS on the web.

It was a good reminder that the fundamentals state, props, and component structure carry over from React to React Native, even when the styling and navigation patterns are completely different.

Building a Lead Qualification Workflow in n8n

September 15, 2026

Being so fascinated by AI Automation I decided to explore it by building a workflow in n8n that starts the moment someone submits a form. It reads the budget they entered and decides whether the lead is a fit, then sends the right email without me touching anything.

A Switch node splits the flow into two branches based on budget rules. Leads who meet the budget get an acceptance email through Gmail, and the rest get a polite decline. Each branch then appends a row to Google Sheets, so I always have a record of who applied and what they were told.

This project pushed me to think in triggers and branches instead of code line by line. Getting the Switch rules right and mapping form fields into the email and sheet nodes took the most testing.

Building an AI Quiz Generator with React, FastAPI, and Gemini

August 2, 2026

To get more comfortable with Full-stack development i started this project that generates custom quizzes from any topic a user types in, using the Gemini API to write the questions. I built the frontend in React.js and a FastAPI backend to handle the prompt logic and parse Gemini's responses into a clean, structured format.

The biggest challenge was getting consistent, well-formatted output from the model so the frontend could reliably render questions and answer options. I ended up being very explicit in my prompts about the exact JSON shape I needed back, which made parsing on the FastAPI side much more predictable.

Working across the React frontend and FastAPI backend gave me a much clearer picture of how a full-stack AI app actually fits together, from user input all the way to a validated API response.

Building My Portfolio Site from Scratch

June 20, 2025

I decided to build my personal portfolio website using only HTML, CSS, and JavaScript — no frameworks, no templates, just raw code. The goal was to learn how layout, responsiveness, and deployment work from the ground up.

The site is fully mobile-responsive, with a dark-tech aesthetic and minimal UI inspired by developer portfolios. I host it on GitHub Pages so that it's free, fast, and easy to maintain. Styling is done using custom CSS, and I’ve avoided any libraries to keep performance sharp.

This project helped me understand grid layouts, media queries, and version control with Git. I also added smooth transitions and button hover effects to keep the UI interactive and clean.

What I Learned Building a Python Medication Tracker

June 10, 2024

My Pet Health Tracker was an academic project of DSA, a desktop GUI app with full CRUD functionality, letting users manage pet profiles, vet history, and medication schedules in one place.

For storing pet profiles, I used a simple list structure to keep things dynamic and easy to update. Medication history is stored in a dictionary keyed by pet ID, which made lookups fast and straightforward. The interface is built with Python's GUI tools, wiring up each CRUD action to its own event handler.

This project boosted my understanding of GUI programming in Python and how to pair core data structures with a real-world application. Getting the CRUD operations to update the interface cleanly was the trickiest part, but it taught me a lot about keeping application state and UI in sync.

Debugging the Playlist Manager (C++)

May 25, 2024

I built a music playlist manager using a doubly linked list in C++. The app allows users to add, delete, and search songs. It even includes logic to find the mid-track and sort the playlist alphabetically.

One tricky bug I faced was accidentally corrupting the `prev` pointer when deleting the head node. It helped me understand edge cases in pointer manipulation better. I also learned how to reverse traverse the list for “previous track” functionality.

This project really taught me that mastering DSA isn't about memorizing, it's about solving problems with structure. Debugging pointer-based logic improved my thinking around memory, structure, and algorithm efficiency.
