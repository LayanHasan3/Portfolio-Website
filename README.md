# CodeWithLayan — Portfolio

Personal portfolio of **Layan Hasan**, a Computer Science student at the University of Karachi who builds full-stack web apps, AI-powered tools, and automated workflows.

**Live site:**

## Pages

- **Home** — intro, featured projects, about, education, certifications, and skills
- **Projects** — full project list with screenshots, tech tags, and GitHub links
- **Blog** — short write-ups on what I learned building each project
- **Contact** — message form (via Formspree) and social links

## Featured projects

| Project            | Stack                         |
| ------------------ | ----------------------------- |
| AI Quiz Generator  | React.js, FastAPI, Gemini API |
| Lead Qualification | n8n, Gmail, Google Sheets     |
| DailyTasks         | React Native                  |
| Pet Health Tracker | Python (GUI)                  |
| Portfolio Website  | HTML, CSS, JavaScript         |

## Tech used

Plain HTML, CSS, and JavaScript with no build step. Fonts are Inter and JetBrains Mono (Google Fonts), and scroll animations use [AOS](https://github.com/michalsnik/aos).
